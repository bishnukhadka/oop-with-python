# 1. Create a Database

A database is a container that stores one or more tables.

```text
Database Server
│
├── company
├── school
└── hospital
```

## CREATE DATABASE

```sql
CREATE DATABASE company;
```

Creates a new database named **company**.

---

## USE

```sql
USE company;
```

Selects the database for further operations.

---

## ALTER DATABASE

```sql
ALTER DATABASE company;
```

Modifies database attributes.

---

## DROP DATABASE

```sql
DROP DATABASE company;
```

Deletes the database permanently.
